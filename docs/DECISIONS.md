## หัวข้อที่ยังไม่ตัดสินใจ (ต้องเคลียร์ในเฟสถัดไป)

| หัวข้อ | เฟสที่ต้องตัดสิน | หมายเหตุ |
|---|---|---|
| ยืนยันวิธี hash รหัสผ่าน (scrypt ตามที่ทำไว้ หรือเปลี่ยนเป็น bcrypt/argon2) | ยังค้าง — ใช้ scrypt ไปแล้วใน Phase 2 | ถ้าเปลี่ยน แก้ที่ `apps/api/src/common/password.ts` ที่เดียว — user ที่มีอยู่ต้อง reset รหัสหรือเขียนโค้ดรองรับ 2 scheme |
| Refresh token / logout (ตอนนี้มีแค่ access token อายุตาม `JWT_EXPIRES_IN`) | Phase 7 หรือ 8 | ถ้าต้องการ logout จริง (เพิกถอน token ก่อนหมดอายุ) ต้องมี token blacklist หรือ refresh token rotation — ปัจจุบันการปิดบัญชี (`isActive=false`) ตัดการใช้งานได้ทันทีอยู่แล้ว |
| Rate limit ของ `POST /auth/login` | Phase 8 | อยู่ใน checklist Phase 8 แล้ว (`ตรวจความปลอดภัยพื้นฐาน: rate limit login`) |
| แก้ข้อมูล certificate ด้วยมือได้หรือไม่ (ถ้าได้ import รอบถัดไปควรทับหรือไม่) | Phase 7 | Phase 4 ทำเป็น read-only ไว้ก่อน — ควรตัดสินพร้อมหน้า Certificate Detail จริง |
